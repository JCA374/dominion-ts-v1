Speed

Machine: a 4-core / 8-thread laptop CPU (Intel i5-8250U: 256 KB L2 per core, 6 MB L3; AVX2, FMA, F16C), 7 GB RAM, no GPU. All search code is C (c/ts.c + the engine), called through ctypes. Every number below is measured, the benchmark is experiments/speed/bench.c (teacher-label games of c2 vs c2; it prints a checksum of every graded value), and each change was checked bit for bit: same checksum, and whole teacher games identical to bv-v1's untouched library (experiments/equiv.py).

So the laptop does at most ~4 processes' worth of rollouts, and the same games now cost 1.6× less. For the advisor that is ~60% more draws in its 3 seconds; the decision bank says more draws lower the teacher's regret.

Other measurements

Value-net leaves after D = 2 / 4 / 8 turns cost 0.08 / 0.20 / 0.39 of a full rollout (they were dropped for bias, not speed). Advisor teacher with 3 processes: 2.4× the draws of one process in the same second (idle).
